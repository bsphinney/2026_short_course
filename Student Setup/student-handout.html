Getting Started with Claude Code

Student setup handout — install the tool and connect it with the class key.

What you need from your instructor: the course API key — a long string that starts with sk-ant-…. Everyone in the course uses this same key. Treat it like a password: don't post it publicly, don't commit it to a public GitHub repo.

1 Install Claude Code

Open a terminal and run the command for your operating system.

macOS / Linux

curl -fsSL https://claude.ai/install.sh | bash

Windows — PowerShell

irm https://claude.ai/install.ps1 | iex

On Windows, PowerShell is recommended. Installing Git for Windows is optional but gives Claude Code a better shell.

Confirm it worked — this should print a version number:

claude --version

2 Add the class API key

Set the key as an environment variable named ANTHROPIC_API_KEY. Replace sk-ant-YOUR-CLASS-KEY with the exact key your instructor gave you.

macOS / Linux

# adds the key to your shell so Claude Code finds it
echo 'export ANTHROPIC_API_KEY=sk-ant-YOUR-CLASS-KEY' >> ~/.zshrc
source ~/.zshrc

Using bash instead of zsh? Replace ~/.zshrc with ~/.bashrc.

Windows — PowerShell

setx ANTHROPIC_API_KEY "sk-ant-YOUR-CLASS-KEY"

After setx, close and reopen your terminal so the new variable loads.

3 Start Claude Code

Move into a project folder and launch it:

# go to whatever folder you're working in
cd my-project
claude

Claude Code opens an interactive session. The first time, it detects the key and asks you to approve it — say yes. You're connected.

4 Try your first prompts

Just type what you want in plain language. A few to get going:

  • "Explain what this project does."
  • "Write a Python function that … and add a test for it."
  • "Find the bug that's causing … and fix it."

Useful in-session commands: /help lists everything, /model switches the model, and /exit ends the session.

This is a shared course budget ($500 for the whole class). That's plenty for everyone when it's used sensibly — but it's shared, so please:
  • Stay on the default (mid-tier) model unless an assignment says otherwise — switch with /model. It's much cheaper and fine for proteomics data-analysis work.
  • Have Claude Code read your data files from disk rather than pasting big tables into the chat — huge protein/peptide files eat budget fast.
  • Don't leave a session running or loop it on giant tasks, and /exit when you're done.
If Claude Code stops responding with a billing/limit error, the class may have reached the shared $500 cap — let your instructor know.
